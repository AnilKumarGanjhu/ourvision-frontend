# OUR VISION Frontend

React + Vite admin/member portal UI.

## Run
1. Install Node.js 18+.
2. Copy `.env.example` to `.env` if you want to override the API URL.
3. `npm install`
4. `npm run dev`
5. Open http://localhost:5173

The UI connects to the Spring Boot API at `http://localhost:8080/api` by default.
Dev login: `admin@ourvision.org` / `Admin@123`.

Overview, Members, Contributions, Meetings and Events have API-connected starter flows. Community Feed, Programs, Business Ideas, Suggestions, Notifications and Settings are UI previews and require the remaining backend endpoints to become fully functional.
